Index Registry

ControlUp · Field-level reference for about 1,700 data fields · In progress

The product’s data fields had no descriptions or units, which slowed advanced users and internal staff who build custom reports, scripts, and alerts. Other people have had AI pull descriptions from the code before, but nobody was willing to verify and publish a list for customer use.

I built a tool to generate descriptions, compare them to data from real environments, and flag anything unusual for me to manually test and verify. We now have a source of information that we can stand behind with confidence that speeds up customer time-to-value and reduces customer tickets. This project blends AI automation with old-school manual testing, without either of which it wouldn't be possible.

Agent distribution and installation for Windows

ControlUp · Deployment guide

Installing the agent is the first hurdle for most customers, and mass deployment through a Windows image was a frequent source of support tickets. This guide takes an administrator from a single install to a repeatable rollout, and is the result of many conversations with the Customer Support team to learn where customers get stuck.
