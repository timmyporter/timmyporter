Selected published work

Steps to using the MIL Classification module

Matrox Imaging · User guide for a C++ machine vision SDK

A walkthrough for developers who build image classification models with the SDK. I wrote the guide covering dataset creation and labeling, model training, and implementing the model in manufacturing and production environments. I also wrote the reference for the C++ SDK.

Index Registry

ControlUp · Field-level reference for about 1,700 data fields · In progress

About 1,700 data fields had no descriptions or units, which made it hard for advanced users and internal staff to build reports, scripts, and alerts. I built a tool that drafts each description from the source code, compares it against live data from real environments, and flags anything unusual. I manually tested every flagged item before publishing, so the reference is one we can stand behind.

ControlUp API documentation

ControlUp · Public API reference and guides · Built from scratch

When I joined, ControlUp had no public APIs. I built the documentation site and wrote the reference and guides as APIs shipped, covering around 400 endpoints across 7 products. I started by writing OpenAPI specifications by hand, then moved to an AI-assisted workflow that drafts and reviews documentation before it is published.

Agent distribution and installation for Windows

ControlUp · Deployment guide

Installing the agent is the first hurdle for most customers, and mass deployment through a Windows image was a frequent source of support tickets. This guide takes an administrator from a single install to a repeatable rollout, and is the result of many conversations with the Customer Support team to learn where customers get stuck.

How I work

  • I test documentation against the real product, including live API endpoints, before it is published.
  • I write for the reader’s task. A developer integrating an API and an administrator rolling out software need different pages.
  • I check content for accuracy, including AI-generated drafts, and remove claims that I can’t verify.
